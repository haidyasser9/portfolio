Haidy Yasser - portfolio website
================================
Everything is inside index.html (images, resume PDF, fonts load from Google Fonts).

Publish it for free (pick one):
1. Netlify Drop: go to app.netlify.com/drop and drag this whole folder in.
2. GitHub Pages: create a repo, upload index.html, then Settings > Pages.
3. Vercel: drag the folder into vercel.com/new.

Edit text: open index.html in any code editor and search for the words you want to change.
Custom domain: buy one (e.g. haidyyasser.com) and connect it in Netlify > Domain settings.
